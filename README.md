# Nova Store

Modern ve responsive bir e-ticaret vitrin sitesi. Proje herhangi bir build aracı gerektirmeden doğrudan tarayıcıda çalışır.

## Özellikler

- Responsive ana sayfa ve mobil menü
- Ürün kartları ve kategori filtreleri
- Ürün arama
- LocalStorage destekli sepet
- Sepet drawer'ı ve demo ödeme akışı
- E-posta bülteni formu

## Çalıştırma

`index.html` dosyasını tarayıcıda açabilir veya bir statik sunucu çalıştırabilirsiniz:

```bash
npx serve .
```

Ödeme entegrasyonu ve gerçek ürün yönetimi için bir backend/ödeme sağlayıcısı eklenmesi gerekir.
